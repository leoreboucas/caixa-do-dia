Política de Privacidade

Aplicativo: Daily Report Flow (Caixa do Dia). Última atualização: 24 de outubro de 2026.

Dados que ficam no seu celular

Os caixas, compras, produtos e valores que você registra ficam guardados somente no armazenamento do seu aparelho. O aplicativo funciona sem internet e não possui servidor próprio: nós não recebemos, não acessamos e não vendemos esses dados.

Login com o Google e backup (opcional)

Se você optar por ativar o backup, o aplicativo pede acesso à sua conta Google com a permissão drive.appdata. Ela permite apenas criar, ler e atualizar um arquivo na pasta privada do aplicativo no seu Google Drive. O aplicativo não acessa nenhum outro arquivo seu no Drive.

  • O e-mail da conta é usado só para mostrar, na tela de Backup, qual conta está conectada.
  • O arquivo de backup contém os seus caixas, compras e produtos, e fica na sua conta do Google.
  • O acesso é usado somente para fazer o backup e restaurá-lo. Nada é enviado a terceiros.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

O que não fazemos

Não usamos anúncios, não coletamos estatísticas de uso, não rastreamos você e não compartilhamos dados com ninguém.

Como apagar seus dados

  • Para desligar o backup, use "Desconectar a conta" na aba Backup.
  • Para remover o arquivo do Drive, revogue o acesso do aplicativo em myaccount.google.com/permissions; os dados da pasta privada do app são apagados junto.
  • Para apagar os dados do celular, desinstale o aplicativo ou limpe os dados dele nas configurações do Android.
